## ✨ Возможности

| Элемент | Действие |
| :--- | :--- |
| Энкодер (вращение) | Громкость ±1% при медленном, до ±10% при быстром (адаптивный шаг) |
| Энкодер (кнопка) | Mute / Unmute звука |
| Свитч 1 | Следующий трек |
| Свитч 2 | Предыдущий трек |
| Свитч 3 | Пауза / Воспроизведение |
| Свитч 4 | Mute / Unmute микрофона |
| OLED-дисплей | Громкость (полоска + %), состояние микрофона, индикатор MUTE |
| Встроенный светодиод D13 | Индикатор состояния микрофона |
| После сна ПК | Автоматический перезапуск через Планировщик Windows |

### Особенности

- **Единая шкала с Windows** — проценты на дисплее совпадают с микшером.
- **Двусторонняя синхронизация** — изменение громкости извне отражается на дисплее.
- **Адаптивный шаг** — медленное вращение = точная подстройка, быстрое = резкое изменение.
- **Заставка при сне** — спящее лицо с `zZz`, когда ПК уходит в сон.

## 📐 Схема подключения

### Arduino Nano

| Компонент | Пин | Примечание |
| :--- | :--- | :--- |
| Энкодер CLK | `D2` | Прерывание |
| Энкодер DT | `D3` | Прерывание |
| Энкодер SW | `D4` | Кнопка → mute звука |
| Энкодер + | `5V` | |
| Энкодер GND | `GND` | |
| Свитч «Трек вперёд» | `D6` | Второй контакт → GND |
| Свитч «Трек назад» | `D7` | Второй контакт → GND |
| Свитч «Пауза» | `D5` | Второй контакт → GND |
| Свитч «Mute микрофона» | `D8` | Второй контакт → GND |
| Встроенный светодиод | `D13` | Уже на плате |

### OLED-дисплей

| Дисплей | Arduino Nano |
| :--- | :--- |
| GND | GND |
| VCC | 5V |
| SCL | **A5** |
| SDA | **A4** |

**Важно:** пины `D0` и `D1` не использовать — они заняты USB-связью.

## 💻 Софт

### Arduino

- **Библиотеки:** `Adafruit_SSD1306`, `Adafruit_GFX`, `Wire`
- **Файл:** `controller_v2.ino`
- **Скорость Serial:** 9600 baud

### Python (Windows)

- **Python 3.13** — `%LocalAppData%\\Programs\\Python\\Python313\\`
- **Библиотеки:**
    - `pyserial` — чтение COM-порта
    - `pycaw` — управление громкостью и mute
    - `comtypes` — зависимость pycaw
    - `keyboard` — эмуляция медиа-клавиш
- **Файл:** `controller_v2.py`
- **Запуск:** через `pythonw.exe` (без окна)

### Системные задачи

- **Планировщик:** задача `MediaControllerWake`, событие `Microsoft-Windows-Power-Troubleshooter` (EventID 1).

## 🚀 Установка

### 1. Прошивка Arduino

1. Установите **Arduino IDE**.
2. Установите библиотеки: **Sketch → Include Library → Manage Libraries** → `Adafruit SSD1306`, `Adafruit GFX Library`.
3. Подключите Nano по USB.
4. **Tools → Board** → `Arduino Nano`.
5. **Tools → Processor** → `ATmega328P` или `ATmega328P (Old Bootloader)`.
6. Откройте `controller_v2.ino`, залейте.

### 2. Установка Python-скрипта

**Автоматически:** запустите `setup.bat` **от имени администратора**.

Скрипт:
- Проверит Python 3.13.
- Установит библиотеки.
- Создаст задачу `MediaControllerWake`.
